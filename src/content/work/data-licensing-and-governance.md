## The problem

Aurora's products combine its own data with data bought from third parties. Every dataset needs clear answers: who may see it, whether it can be redistributed, used to train AI or embedded in a client's model, and who is responsible for its quality.

## What I did

- Own acquisition and licensing for more than 40 licensed data sources, alongside open data, and set usage terms for Aurora's own and third-party data together with the legal team.
- Own entitlements: which clients can access which datasets, and on what terms.
- Led a review that gave every table a named owner and checked each one for value and usage, so unused tables could be retired.
- Designed a monitoring framework with colleagues: each table has its own expected publishing delay, and an alert fires when data doesn't arrive on time.

## The result

- More than 40 licensed sources managed under clear usage terms.
- Every table governed, with a named owner.
- Over 80% of tables monitored automatically. The framework is live and still being improved.

## Now working on

- Data contracts for every data asset, using an open-source data contract standard, so that how each asset is governed is easy to find.
- Tracking data lineage, so it's clear where each dataset comes from and what depends on it.
